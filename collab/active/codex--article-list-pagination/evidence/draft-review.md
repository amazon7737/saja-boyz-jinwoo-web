# 독립 초안 리뷰

2026-10-11 · 검토자: 별도 컨텍스트 `review_list_pagination_draft`.

## 범위

명세·헤더·테스트 3개, 실제 목록 페이지와 기존 테스트, 공용 조회 함수, 머지된 검색 페이지네이션을 읽기 전용으로 대조했다. 검토자는 이 checkout에서 파일 수정과 테스트 실행을 하지 않았다.

## 반영한 지적

기존 초안의 중복 검증은 이미 표시된 ID 위주였다. 추가 페이지 내부에 새 ID가 두 번 등장하는 경우를 넣어 첫 제목 유지·한 카드 표시·원본 2행만큼 offset 전진을 확인하도록 수정했다.

최종 흐름의 offset은 0 → 20 → 40 → 42이며 마지막 1행을 받은 누적값 43이 최신 total 43에 도달한다. 짧은 페이지여도 아직 total이 남아 있을 때는 계속 조회한다.

## 철회한 지적

정규식 역슬래시가 이중으로 보인다는 초기 지적은 도구 출력의 JSON escaping을 원문으로 오인한 것이었다. 실제 바이트와 동작을 확인해 철회했다. 수치 갱신 이후 최종 정규식도 단일 역슬래시를 사용한다.

## 최종 결과와 한계

수정된 원본 테스트와 실행 계획의 동기화를 재확인했고 추가 지적은 없었다. 실제 구현·Next 서버 액션 전송·브라우저 동작 검증을 대신하지 않는다. 해당 검증은 승인 후 별도로 수행한다.
