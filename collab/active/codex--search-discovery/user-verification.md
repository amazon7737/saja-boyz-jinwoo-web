# Google 소유권 확인 태그 추가 지시

사용자가 SEO 작업 중 HTML 태그 방식의 실제 확인 값을 직접 제공했고 해당 값으로 소유권 확인을 진행하도록 지시했다. 초기 명세의 “사용자 지정 인증코드를 만들지 않는다”는 임의 발급 금지이며, 실제 사용자 제공 값의 적용을 막는 조건이 아니다.

- `src/app/layout.tsx`의 공통 `Metadata.verification.google`에 제공 값을 그대로 설정했다. 수동 head 태그를 중복 추가하지 않았다.
- 작은 설정 변경이므로 기존 승인 명세·테스트 본문·기대값은 바꾸지 않았다. 실제 운영 모드 HTML의 7개 경로에서 값과 중복 부재를 확인했다.
- 확인 코드는 공개 HTML 값이다. 계정 로그인이나 Search Console 등록·확인 버튼 조작은 하지 않았다. 실제 소유권 확인은 dev→main 운영 배포 후 사용자가 실행한다.
