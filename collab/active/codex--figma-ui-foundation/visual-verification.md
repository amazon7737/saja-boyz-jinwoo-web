시각 대조 후 화면 여백·캔버스·지도 컨트롤 배치를 앱 측 Sobaya 실행 어댑터의 별도 Astra 소스 작업으로 보강했다. 이는 신규 TDD 항목이나 승인 receipt가 아니다. 부모 에이전트는 원본 조회·명세·검증·문서·Git을 담당했다. Sobaya 런타임·승인 기준·테스트는 변경하지 않았다.

네 체크포인트 외 보강 작업은 여섯 번이다(화면 틀, 지도 컨트롤, 부착 순서, 기본 컨트롤 보존, 비동기 삽입 배치, Map init 시점 연결). 최종 방식은 공개 map.controls/KVOArray로 SDK의 기존 컨트롤을 배치한다. padding은 컨트롤에 효과가 없었고 새 MapDataControl은 내용이 비어 실제 브라우저 검증에서 폐기했다. 원본 SDK 로고·저작권·축척·데이터 갱신을 유지하고 listener/frame/transform은 종료 시 정리한다.

기존 오류 경계 두 테스트가 요구하던 흉흉 DOM 텍스트는 SVG 옆 화면 읽기 도구용 텍스트로 유지했다. 기존 기대값을 바꾸지 않았다. 작업자 sandbox의 포트 EPERM은 호스트 검증으로 구분했고 실패한 Turbopack 생성 캐시만 정리했다. 기본 build 명령이나 의존성을 우회하지 않았다.

최종 코드 커밋의 전체 gate·새 read-only 독립 review 결과와 SHA는 마지막 인수인계 저널에 기록한다. 계획 이동은 검증 뒤 마지막 메타데이터 커밋이다.

## 실제 브라우저

기본 Next production build와 실제 Chrome·Naver SDK·운영 API 읽기 전용 연결로 지도/검색/결과/목록/상세/제보를 촬영했다. FontFaceSet에서 Inter/Pretendard(100–900) loaded, 로컬 woff2 요청을 확인했고 원본 자산 SHA256도 일치한다. 제품에는 원격 Figma 자산 URL이나 시안 스크린샷을 사용하지 않는다.

393×852 실측: 헤더52px, x16px/너비361px, 지도 top8px/목록 top12px, 메뉴68px/radius28px/bottom8px, 제보54×54px, SVG64×24px. 320×700, 667×375, 1440×900의 모든 주요 라우트에서 가로 overflow와 메뉴 가림이 없었다. 네이버 저작권이 메뉴와 선택 시트 위에 있는 것도 실제 SDK로 확인했다. 수치는 browser-metrics.json에 저장했다.

검색 이동·실제 결과·상세 직접 진입/새로고침·공유 미지원 상태를 별도 주입한 클립보드 대체, 합성 기사6개 선택/전부 표시/가로 화면 닫기, 긴 제목·이미지 없음·빈 결과·404·API500 안내를 확인했다. 합성 데이터는 로컬 시각 검증용이며 운영 제보 POST나 배포는 실행하지 않았다. 모바일 OS 공유창은 실기기에서 확인할 항목이다.
