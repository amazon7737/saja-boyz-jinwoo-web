# fix(article): 상세 API 오류에서도 복귀 탐색 유지

## 목표와 범위

PR19의 상세 전용 화면에서 API 오류가 지속되어도 앱 내부로 복귀할 수 있게 한다. 정상 상세와 API 오류가 같은 전용 탐색을 사용하며 목록으로(/incidents)·닫기(/) 링크를 제공한다. 오류 안내와 현재 기사 재시도 링크는 유지한다. 공통 검색 헤더/주 메뉴를 오류 화면에 다시 추가하지 않는다.

복귀는 브라우저 history 유무에 의존하지 않는 실제 링크이며 직접 진입도 지원한다. 500·요청 거부·timeout 거부·JSON 실패·기사 응답 계약 실패·API 주소 미설정에서 오류 안내/복귀/재시도를 유지한다. 기존 404·잘못된 ID, 정상 기사·이미지·공유, API 요청/5초 제한과 기존101개 테스트·mock·fixture·전체 테스트 명령을 변경하지 않는다.

전용 탐색은 상세 기능 내부의 작은 컴포넌트 또는 함수로 공유한다. 새 의존성/전역 아키텍처 변경/다른 디자인 변경은 없다. 소바야 런타임과 이미 보관한 공통 기반 계획은 수정하지 않는다.

## 완료

새 테스트1개를 정확한 초안으로 probe하고 승인받은 뒤 소바야 RED/GREEN·전체102개·gate·새 독립 리뷰를 수행한다. format/lint/typecheck와 기본 production build를 검증한다. 로컬 API500/요청 실패 모의 응답으로 직접 진입/재시도/목록·지도 복귀와 정상 헤더를 실제 브라우저에서 확인한다. 운영 제보 POST·배포는 하지 않는다.

검증한 src 변경과 회귀 테스트를 기존 PR19에 반영하고 커밋·푸시·CI를 확인한다. GitHub 코멘트는 수정 결과와 검증을 담은 초안만 사용자에게 보여주고 게시하지 않는다.
