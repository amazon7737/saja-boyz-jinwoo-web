# 공통 디자인 자산 출처

제품 자산은 소바야 워커가 적용한다. 준비된 원본은 .claude/cache/design-assets/에 있다. Figma 참조 이미지는 같은 경로의 figma/ 디렉토리다. 스크린샷은 대조용이며 제품 배경에 사용하지 않는다.

- Pretendard Variable v1.3.9: 공식 orioncactus/pretendard, 고정 커밋 5c41199ea0024a9e0b2cb31735265056e5472d76, packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2. 원본 LICENSE를 같이 보관한다.
- Inter Variable v4.1: 공식 rsms/inter, 고정 커밋 e3a3d4c57d5ecc01453a575621882a384c1995a3, docs/font-files/InterVariable.woff2. 원본 LICENSE.txt를 같이 보관한다.
- map-pin.svg: Figma 노드19:2527/18:2428, 원본22×22px·viewBox 0 0 22 22. 변경하지 않는다.
- filter.svg: Figma 노드45:3713/18:2368, 원본18×18px·viewBox 0 0 18 18. 변경하지 않는다.
- brand-proposal.svg: 사용자 지시로 만든 흉흉 창작 로고, 이 폴더의 원본을 사용한다. viewBox 0 0 128 48, 표시64×24px. Figma 원본 로고를 교체하는 명시적 예외다.

자산 크기·SHA256은 asset-manifest.json에 고정한다. Figma 임시 다운로드 URL은 공개 기록에 남기지 않는다. 원본 SVG의 root 치수 및 path를 변경하거나 그림을 다시 그리지 않는다.

공식 폰트 문서: https://github.com/orioncactus/pretendard 및 https://github.com/rsms/inter .
