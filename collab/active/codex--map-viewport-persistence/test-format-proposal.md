# 승인 테스트 초안 포맷 수정 제안

승인 전에 초안의 Prettier 검사를 빠뜨렸다. 기존 테스트를 바꾸는 변경은 아니지만 새 초안의 헤더와 본문을 정확 기준으로 승인받았으므로 자동 수정하지 않는다.

- failed-test-format-proposal.md는 기존 신규 3개 테스트와 공유 헤더의 Prettier 형식만 수정한 정확 대체안이다.
- 테스트 이름·기대값·SDK fixture 동작·import·경로·assertion·명세·기존 61개 테스트·명령을 유지한다.
- 승인되면 현재 항목 실패 상태에서 보호 입력 변경 절차를 확인한 후 대체 초안을 등록하고 approve --replace로 기준을 다시 승인한다. 구현 체크포인트를 숨기거나 기존 테스트를 삭제하지 않는다.
