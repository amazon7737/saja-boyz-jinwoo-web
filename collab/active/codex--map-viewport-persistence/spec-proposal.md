# 지도 이동 상태 복원 명세 초안

## 동작
- 최초 방문은 서울 중심(37.5665, 126.978), 확대 12를 유지한다.
- SDK 지도 인스턴스를 정상적으로 정리하기 전에 실제 getCenter/getZoom 값을 읽어 탭 런타임 메모리에 보관한다. 목록·상세·검색 등으로 이동 후 지도에 돌아오면 같은 clientId의 마지막 중심·확대 수준으로 생성한다.
- 반복 이동에서는 가장 최근 값을 사용한다. clientId가 다르면 기본 위치에서 시작하며 저장된 상태는 하나만 유지한다. 새 문서 로드·새 탭에서는 기본값이다.
- 읽기 실패·메서드 부재·NaN·무한대·좌표 범위 밖·SDK 확대 범위 밖(0~21)은 기존 유효 상태를 덮어쓰지 않는다. 이 경우에도 기존 SDK 정리와 오류/재시도 흐름은 유지한다.
- 위치 권한을 자동 요청하지 않고, 내 위치 버튼의 기존 동작을 유지한다. 마지막 지도 중심에는 사용자가 이동한 내 위치도 포함될 수 있지만 마커·정확도·위치 응답 자체는 보관하지 않는다.
- localStorage/sessionStorage/쿠키/서버 전송을 사용하지 않는다. 새 전역 store·제품 의존성·UI 변화·주소 검색·사건 마커·API 계약 변경은 없다.

- 최소 지도 모델 모듈과 기존 MapHome 생명주기 연결. 신규 테스트는 map-home 폴더에 모으며 기존 61개 테스트와 helper·fixture·명령은 변경하지 않는다.
- failed-test-proposal.md의 정확 헤더·신규 3개 본문을 승인 후 sobaya로 실행한다. gate·독립 review·타입·빌드·Chrome의 지도 이동/목록 이동/재진입과 모바일 크기 검증 후 dev 대상 PR을 작성한다.
