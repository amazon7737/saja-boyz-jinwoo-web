# 사용자 추가 요청: 필요한 곳의 절제된 인터랙션

사용자가 대부분의 화면 동작은 확인했으며, 앱이 정적으로 느껴져 과하지 않은 애니메이션과 인터랙션을 필요한 곳에 나눠 달라고 요청했다.

- 필터 드롭다운·전체필터/지역 선택 시트의 짧은 진입 효과.
- 실제 클릭 가능한 버튼·링크의 눌림 반응과 선택 색상 전환.
- 검색 결과 교체의 짧은 진입 효과. 항목별 순차 등장·무한 반복·지도 카메라 임의 이동은 추가하지 않는다.
- 기존 포커스·키보드·닫기·inert/스크롤 복구·API·공유·입력·레이아웃/치수·SDK 수명주기를 보존한다.
- prefers-reduced-motion: reduce에서는 공간 이동/등장 애니메이션을 끄며 disabled에는 눌림/hover 활성 반응이 없다.
- 의존성·JS 애니메이션 라이브러리 없이 소유 UI 클래스와 범위가 정해진 CSS로 구현한다. 제보 본문은PR22 소유이므로 수정하지 않는다.
- 승인 테스트·plan은 변경/추가하지 않는다. 새 소스 보정 뒤 기존109개 전체gate·실제브라우저·새독립리뷰를 수행한다.
