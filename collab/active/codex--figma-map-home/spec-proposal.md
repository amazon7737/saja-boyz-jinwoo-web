## 지역 숫자 원

- 현재 API의 precision=region은 서버 카탈로그의 고정 행정구역 대표점이다. 지역명과 대표 좌표를 그대로 보존해 집계하고 article_id 중복은 첫 항목만 센다. 줌/이동에 따라 합치거나 수를 바꾸지 않는다. 시/구/동을 임의로 합치거나 주소를 프런트에서 추론·지오코딩하지 않는다.
- 과거 address/neighborhood 위치는 반환된 점을 유지하고 동일 좌표만 묶되 정확한 지역 대표점이라고 오표시하지 않는다. 모든 기사 집계 표시는 1건부터 숫자 원이며 개별 작은 점 모양을 사용하지 않는다. 파란 내 위치 표시는 별개다.
- 1~5건38.4px·6~9건48px·10건 이상72px, 흰 숫자와 빨강60%·흰 테두리·원본 그림자. 선택 ring/aria-pressed와 Enter/Space 선택·닫기 후 포커스 복귀 유지.
- 지역 선택 시 고유 기사 전체를 기존 상세 시트로 열고 실제 상세 링크를 유지한다. 작은 점 SVG를 요구하던 기존 테스트1개는 숫자 원 기대값으로 정확히 갱신할 승인을 받는다.

## 하단 기사 카드와 배치

- 지도 하단 메뉴 위에 그라데이션·제목·전체보기와 가로 스크롤 카드를 둔다. 카드200px/간격10px/패딩12px/radius14px/이미지80px/제목13px/발행 정보11px를 원본에 맞춘다. 모바일320/393과 가로667/데스크톱1440에서 지도·메뉴·선택 시트가 카드/내 위치/SDK 저작권을 가리지 않도록 한다.
- API에 인기 점수가 없으므로 헤더는 '최근 보도 기사', 발행일 최신순/동률 입력순, 고유 기사만 표시한다. 유효하지 않은 발행일은 전체 기간에서 뒤에 두고 '발행 시각 미확인' 표시. 제목은 텍스트로 안전하게 표시하고 전체보기는 /incidents, 제목 링크는 실제 /incidents/{article_id}.
- 기존 검증된 이미지 URL 정책과 AI 생성 이미지 표기를 유지한다. 사진 없음/실패 대체. 동적 기사를 Figma 예시 화재 사진으로 대체하거나 없는 상태·분류 배지를 만들지 않는다.
- 큰 '지도 기사 N건 / 기사 위치 보기' 패널은 제거하고 기존 전체 기사 위치 이동 동작은 작은 보조 버튼으로 유지한다. 지역 좌표 출처는 출처 행/설명에서 유지한다. 기존 선택 시트 링크 검사1개는 새 카드와 구분해 시트 내부로 정확히 범위를 좁힌다.

## 필터

- 지도 필터는 MapHome이 실제 데이터와 같은 상태로 소유한다. AppShell은 지도에서 중복 비활성 필터를 그리지 않고, 목록의 아직 미연결 필터는 그대로 유지한다. 이를 고정했던 기존 foundation 테스트1개만 정확히 갱신한다.
- 기간 '전체 기간/최근24시간/최근7일/최근30일'. 기사 pubDate 기준이며 '발행일 기준'을 표시한다. rolling 기간은 now-window 이상 now 이하(양끝 포함), 미래/잘못된 날짜 제외. 전체 기간은 데이터 손실 없이 모두 포함한다. 적용 시 원 집계·카드가 같은 집합으로 바뀌고 선택 시트는 닫는다. 카메라/SDK 인스턴스·이전 뷰포트는 보존한다.
- 카테고리 드롭다운은 전체/사회/안보/정치/국제, 상태는 전체/진행 중/공론화 성공/종결을 원본 형태로 보여 준다. 운영 OpenAPI와 실제82건 기사에서 분류·진행 상태 필드가 전혀 없음을 확인했다. 전체만 선택, 나머지는 disabled와 '분류 정보 미제공'/'상태 정보 미제공' 안내. 효과 없는 가짜 선택이나 제목 기반 추론 금지. 서버 계약 미완료는 협업 문서에 명시한다.
- 각 팝업은 aria-expanded/controls, 선택 상태, Escape·바깥 클릭 닫기·포커스 복귀. 지원되는 기간 선택은 선택 칩 빨강 테두리/색. 카테고리·상태가 실제 선택된 45:3317과는 데이터 미제공 차이를 명시한다.
- 전체 필터 아이콘은 기간·카테고리·상태를 모은 시트. 임시 기간 선택은 적용 전 지도에 반영하지 않고 닫기/취소 시 폐기한다. 초기화+적용으로 전체 복원. 모달 focus trap/배경 접근 차단/스크롤 복구·Escape 닫기를 브라우저에서 확인한다.
- 밝은 전체 필터 전용 시안은 없다. 구형 전체 필터11:1261의 섹션 구성과 밝은34:3259의 패널/버튼 토큰을 조합하되 dark/cyan 구형 테마를 복제하지 않는다. 이는 명시적인 적용안이며 그대로의 원본 일치라고 주장하지 않는다. 기간 직접입력은 이번 범위에서 제외한다.
