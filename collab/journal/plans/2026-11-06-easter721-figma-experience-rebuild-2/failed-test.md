# 행동 시나리오

- [ ] 바텀시트 핸들을 누른 채 드래그하면 손가락 이동에 따라 시트의 위치가 연속적으로 변한다.
- [ ] 바텀시트의 놓기·취소·키보드 조작과 내부 스크롤·포커스 복귀가 유지된다.
- [ ] 지도와 목록의 상태 필터를 제거하고 기간·카테고리 필터를 유지한다.
- [ ] 피그마의 실제 지도·제보·목록 아이콘과 크기를 사용한다.
- [ ] 제보 성공 시 피그마의 완료 화면을 표시하고 닫기와 새 제보 흐름을 제공한다.
- [ ] 제보 입력 화면과 상태의 크기·간격·오류 안내를 피그마에 맞춘다.
- [ ] 검색의 최근 검색어·기사 카드·입력 상태를 실제 API와 피그마에 맞춰 정리한다.
- [ ] 상세 페이지의 진입·복귀·공유 URL과 위치 데이터의 제공 범위를 확인하고 피그마 화면을 구현한다.
- [ ] 직접 기사 주소 GET·HEAD에서 사전 조회가 일시 실패하면 503과 재시도 안내를 반환하며, 정상·404·앱 내부 탐색 및 JavaScript 없는 복구를 유지한다.
- [ ] 지도 카드 제목은 실제 발행일 최신순 정렬을 설명한다.
- [ ] 직접 기사 상세에서 사용할 수 있도록 기존 검증된 지도 기사 중 해당 위치와 같은 지역 기사만 별도 API로 반환한다.
- [ ] 지도 문맥이 없는 상세 페이지는 본문을 즉시 표시하고 검증된 위치 API 응답을 받아 위치와 같은 지역 기사를 표시한다.
- [ ] 상세 문서가 기사를 한 번만 조회해 두 번째 조회 장애로 정상 기사가 200 오류 화면이 되지 않는다.

- 같은 지역의 기사 목록은 인기순처럼 보이지 않도록 같은 지역 기사로 표시한다.

- 검색어 입력 제안은 실제 검색 결과의 제목 최대 다섯 개를 정제해 표시한다.

- 검색 제안의 일치어는 원문 대소문자를 유지해 강조하고 긴 제목을 줄바꿈하며 결과 수를 접근 가능하게 알린다.

- 검색 초기의 일간 인기 기사는 실제 순위와 검증된 상세만 표시하고 빈 결과·오류·시간 초과를 구분한다.

- 검색 입력 중 실제 결과로 제안 최대 네 행과 일치 기사 카드 최대 두 개를 중복 없이 표시한다.

- 목록 키보드 포커스는 스트리밍용 숨김 트리가 아닌 실제 표시 링크에서 전부 검증한다.

- 인기 순위 중복은 첫 순위를 유지하며 제거하고 취소·시간 제한·재시도 중 로딩을 보장한다.

- 검색 입력 중에는 기존 섹션을 감추고, 지우면 복원하며 검색창 포커스와 피그마의 검색 전용 화면을 유지한다.

- 검색 입력 중 복합 검색어는 마지막 단어만 강조하되 기존 검색 결과의 강조 기준을 유지한다.

- 바텀시트 전환 도중 손잡이를 다시 잡으면 현재 위치에서 멈추고 드래그와 재터치에 자연스럽게 반응한다.

- 진행 중 터치 취소나 포인터 캡처 해제는 시트가 목표 높이로 이어지게 하고 다른 포인터 클릭은 활성 드래그를 방해하지 않는다.

- 검색창 아이콘은 브라우저에서 실제로 24px로 렌더링된다.
