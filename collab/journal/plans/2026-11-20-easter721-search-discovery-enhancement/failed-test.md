# 검증할 동작

- 아카이브의 정상·빈 페이지·잘못된 페이지와 API 일시 장애를 구분하고, 직접 GET/HEAD와 클라이언트 재시도에서 오류와 페이지별 canonical이 올바르다.
- 사이트맵은 실제 기사 ID를 안정적으로 제공하고 중복·페이지 경계·중간 API 실패·과도한 조회를 안전하게 다룬다.
- 홈과 내부 링크는 사용자가 볼 수 있는 실제 콘텐츠를 검색엔진에도 제공하며 기존 Figma 화면과 지도 상호작용을 유지한다.
- 기사 공유 정보 개선이 가능하면 실제 기사 데이터만 사용하고, 기존 공유 주소·이미지 대체 경로·404/503을 유지한다.
