# 검색 노출과 공유 보완

기존 PR의 브랜드·지도 동작과 사용자에게 보이는 디자인을 유지하면서 기사 발견 경로와 임시 장애의 검색엔진 응답을 보완한다.

기사 아카이브의 정상·빈 결과, 잘못된 페이지와 일시적인 기사 API 장애를 구분한다. 임시 장애를 정상 페이지의 색인 제외 신호로 오인하게 하지 않고, 직접 진입과 클라이언트 탐색에서 사용자에게 재시도 경로를 제공한다.

사이트맵과 내부 링크가 실제로 존재하는 기사를 안전하게 발견할 수 있도록 기사 API의 페이지네이션·중복·실패를 고려한다. 홈과 공유 화면은 기존 실제 콘텐츠와 디자인을 유지하고, 가능한 범위에서 초기 HTML과 기사별 공유 정보의 유용성을 높인다. 존재하지 않는 정보나 이미지·출처를 만들어내지 않는다.

변경의 색인·검색 순위 또는 AI 인용 효과를 보장하지 않는다. 기존 기사 주소, 로고·공유 이미지, 메타데이터, 404/503, 접근성과 뒤로가기 동작을 보존한다.
