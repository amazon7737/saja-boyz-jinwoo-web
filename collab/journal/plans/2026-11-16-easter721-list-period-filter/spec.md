# 목록 기간 필터

목록의 기간을 전체, 최근 24시간, 최근 7일, 최근 30일로 선택한다. 기준은 기사 발행 시각이다. 목록은 서버의 `GET /news?period=24h|7d|30d`를 사용하며 전체 선택 시 period를 생략한다. 정렬은 기존 최근 30일 인기순을 유지한다.

선택값을 목록 URL에 기록해 새로고침과 상세 진입 후 복귀에도 유지한다. 첫 페이지와 이후 페이지 및 재시도에 같은 기간을 적용한다. 기간 변경 시 예전 목록과 응답이 새 목록에 섞이지 않게 한다. 접근 가능한 기간 선택 메뉴와 선택 결과가 없는 안내를 제공한다.

기간이 지정된 응답은 서버의 `X-News-Period` 헤더가 요청한 기간과 일치할 때만 사용한다. 헤더가 없거나 다르면 필터를 적용한 결과로 보여주지 않고 오류와 재시도를 제공한다. 전체 기간과 다른 화면의 요청에는 이 헤더를 요구하지 않는다.

기사 분류값은 현재 서버 계약에서 확인되지 않아 카테고리는 기존 비활성 상태를 유지한다. 검색·지도·보관함·사이트맵의 기존 조회 계약은 유지한다.
