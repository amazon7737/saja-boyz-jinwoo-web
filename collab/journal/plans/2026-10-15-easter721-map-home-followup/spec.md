# 지도 겹침 묶음과 출처 행 정렬 — 후속 명세 초안

PR23 캡처의 울산 원1·1이 겹치는 점을 고쳐2인 큰 원으로 합친다. 출처 링크와 기사 위치 보기의 중앙 정렬도 함께 고친다.

## 표시 집계
- 원본 지역 그룹과 대표 좌표·정밀도는 유지한다. 현재 화면에서 원이 겹치면 별도 표시 묶음으로 합친다. SDK getProjection().fromCoordToOffset으로 픽셀 거리를 구한다.
- 숫자는 포함된 고유 article_id 수이며 중복 합산하지 않는다. 같은 좌표의 다른 지역도 화면에서는 한 원으로 보인다.
- 묶음 대표는 결정적인 원본 대표점 하나를 사용한다. 행정구역을 합치거나 평균 좌표를 실제 발생 지점처럼 만들지 않는다. 접근성 이름에 묶음을 명시한다.
- 일반 지역 원1~5건38.4/6~9건48/10건 이상72px는 유지한다. 여러 지역을 합친 묶음은 최소48px로 단일1건 원보다 크게 보여2도 구별한다.
- 반지름과 연쇄 겹침·묶음 크기 증가로 남는 겹침을 고려해 결정적으로 정리한다. 확대해 분리되면 원본 지역 원으로 다시 표시한다.
- 초기화·줌/idle·리사이즈·기간 변경에 표시를 갱신하되 SDK 재생성이나 자동 카메라 이동은 없다. 변화 없는 idle에는 마커 DOM·선택을 불필요하게 교체하지 않는다.
- 선택은 기존 시트에 고유 기사 전체를 표시한다. Enter/Space·닫기·포커스 복귀·기간 동기화·오류/재시도·내 위치·출처를 유지하고 마커/리스너는 정리한다.
- 투영을 사용할 수 없는 초기화 단계에는 같은 좌표를 묶고 다른 점은 보존한다. 준비되면 실제 화면 기준으로 갱신한다. 테스트만을 위한 다른 동작을 넣지 않는다.

## 정렬
출처 링크에만 붙은 mt-1(4px)을 제거하고 링크/버튼의 줄 높이와 중앙 정렬을 맞춘다. 텍스트·실제 출처 URL·기사 위치 보기 동작과 좁은 화면 접근성을 유지한다.
