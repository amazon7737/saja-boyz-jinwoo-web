# 검색 입력 안내와 공유 링크 포커스

검색 화면의 빈 입력란에서도 안내 문구가 바뀔 때 자연스럽게 롤링한다. 입력값, 한글 IME 조합, 검색 제출과 초기화, 키보드 포커스 및 접근성 이름을 유지한다. 안내는 입력 중 겹치지 않으며 움직임 줄이기 설정을 존중한다.

공유와 클립보드를 사용할 수 없어 링크를 직접 복사하는 경우에도 입력란의 키보드 윤곽선이 필드 경계에 붙도록 한다.

소바야 워커의 샌드박스에서는 브라우저와 로컬 포트가 제한될 수 있다. 워커는 선택 테스트와 가능한 검사만 실행하고, 전체 테스트와 Chrome 검증은 바깥 오케스트레이터가 실행한다.
