# 읽기 경험·로딩 피드백 개선 — 승인 요청 초안

## 목적
기존 Figma 화면의 정보 구조·색·카드 형태를 유지하며 실제 브라우저에서 확인한 간격·컨트롤 높이 불일치를 해결한다. 검색·목록의 더보기 버튼은 자동 페이지 연결로 교체하고 텍스트만 있는 로딩은 화면 목적에 맞는 시각 피드백으로 교체한다.

## 확인한 기준
- 기준 origin/dev a924bdd (PR23 병합), 작업 브랜치 codex/reading-experience.
- Chrome 320·393·640px에서 가로 넘침 없음. Tailwind padding/gap 유틸리티는 정상 적용된다.
- 검색 form 높이36px 안에44px 버튼이 들어가 위·아래로4px 넘친다.
- 하단 메뉴 양옆 탭과 중앙54px 제보 버튼의 간격0px. 포커스 outline3px + offset4px가 인접 버튼을 침범한다.
- 추천 검색어 높이32px, 패딩12px, 아이콘/글자 사이 explicit gap 없음. 추천 이동 중 전체 로딩 문장이 칩 안에 붙어 폭·줄바꿈을 바꾼다.
- 근거 캡처·측정: collab/active/codex--reading-experience/evidence/baseline/.

## 화면 간격
- 공통 수평 여백16px, 관련 내용8~12px, 섹션20~24px 범위를 기준으로 기존 디자인에 맞게 조절한다. 일괄 치환이나 광범위 CSS reset은 하지 않는다.
- 검색창·뒤로가기 터치 영역은44px 이상으로 맞추고 내부 버튼이 검색창 경계를 넘지 않게 한다. 기본 search 입력·clear 동작 유지.
- 추천 칩 min-height36px, 아이콘/라벨6px 안팎 간격, 칩간8px. pending spinner 자리를 예약해 로딩 전후 칩 폭·높이 변화1px 미만.
- 하단 내비게이션 탭과 중앙 버튼 사이 최소8px. 동일 중심선, 키보드 포커스 표시를 유지하며 외곽이 다른 탭과 겹치지 않게 한다. 가운데 버튼을 키우거나 주변 테두리를 숨겨 해결하지 않는다.
- 목록·검색 결과 카드 간격12px, 내부12~16px. 제목·본문 줄간격을 읽기 편하게 맞추고 좁은 화면에서 텍스트·날짜·원문 링크가 겹치지 않게 한다.
- 지도 캐러셀·필터·상세·제보 폼도 같은 기준으로 감사한다. 실제로 밀집·겹침이 있는 부분만 조절한다. 마지막 콘텐츠·오류 재시도·추가 로딩이 하단 고정 메뉴에 가려지지 않게 safe-area 여유를 둔다.

## 검색·목록 무한 스크롤
- 더보기 버튼은 제거. 실제 목록 뒤 감지 지점이 뷰포트 근처에 왔을 때 다음20개를 요청한다. 두 목록이 같은 방식으로 동작하게 작고 응집된 공통 감지 로직을 둘 수 있다.
- 초기 페이지 즉시 유지. 추가 요청 동안 기존 카드 유지 + 아래 skeleton2개. 한 시점에 요청1개.
- offset은 표시 고유 기사 수가 아니라 API의 원시 수신 개수로 진행. 기존 첫 기사 우선 중복 제거·순서·total 유지.
- 빈 페이지 또는 offset>=total이면 자동 호출 종료. 빈 초기 결과를 오류·로딩으로 바꾸지 않는다.
- 실패 시 기존 카드·offset을 보존하며 오류 안내와 명시적 다시 시도 버튼. 관찰 콜백이 반복되어도 오류 상태에서 자동 재시도하지 않는다.
- 검색어 변경·언마운트 뒤 늦게 온 응답/오래된 관찰 콜백 무시. 관찰자 및 fallback 이벤트 정리. 데이터 요청·시크릿·서버 API 규약은 변경하지 않는다.
- IntersectionObserver 미지원 시 scroll/resize에서 뷰포트 근접 여부를 검사하는 작은 fallback. 초기 관찰 없이 무한 반복 요청하는 구현이나 숨긴 더보기 버튼 금지.
- sr-only로 자동 추가 안내 유지, DOM 키보드 순서와 포커스 유지, 새 카드 수십 개를 한꺼번에 읽어주는 live region 금지.

## 로딩·모션
- 목록 초기/추가: 실제 기사 카드 공간과 맞는 skeleton. 검색 초기/추가: 검색 결과 카드 skeleton. 상세 초기: 상단·이미지·본문 구조 skeleton.
- 지도 SDK 초기 준비/내 위치 요청: 작은 spinner와 접근 가능한 상태. 지도 미설정·오류·빈 위치 안내와 재시도는 유지.
- 추천/최근 검색 이동: 크기 고정된 compact spinner. 제보 접수: 버튼 크기와 기존 접수 중 접근 이름 유지 + spinner. 입력/첨부/재시도 키·타임아웃·Suspensive 경계 동작 유지.
- 접근성 상태 role=status/aria-busy 및 sr-only 텍스트 유지. skeleton 장식은 aria-hidden, 가짜 기사/날짜/링크 없음. 로딩과 빈 결과/오류 구분.
- 기존 진입·누름 피드백에 짧은 카드 진입(140~180ms)·골격 pulse(약1.4s)·spinner 회전 추가. 레이아웃을 움직이는 margin/height 애니메이션, 무한 bounce/큰 확대/과도한 stagger 금지.
- prefers-reduced-motion에서 진입·pulse·회전 모두 정지, 정적 로딩 형태는 유지. 새 라이브러리 추가 없음.
- 이미지 오류·AI 생성 표기·안전한 URL, 검색 강조, 지도 겹침 묶음/카메라/필터, 제보 도메인 로직은 유지.
