# 검색 안내와 화면 전환

- 지도와 목록의 검색 안내가 변경될 때 짧고 자연스러운 세로 롤링 효과를 보여준다. 움직임 줄이기 설정에서는 정적인 안내를 유지하며 검색 링크의 이름과 조작성을 유지한다.
- 지도 기사 미리보기에서 상세 화면에 다녀온 뒤 기존 미리보기의 높이, 스크롤, 포커스를 유지하고 다시 진입하는 애니메이션 없이 즉시 표시한다. 처음 미리보기를 열 때의 애니메이션은 유지한다.
- 지도에서 목록을 열 때 목록 콘텐츠가 지도 화면 위에 떠 보이지 않는다. 목록 화면으로 전환된 뒤 기사 로딩 표시가 보이며 탐색과 키보드 접근성도 유지한다.
