# 최신 브랜드와 지도 화면 전환

피그마에서 확인한 최신 흉흉 로고와 공유 이미지를 실제 서비스의 사용처에 반영한다. 공유 링크와 기존 메타데이터 동작은 유지한다.

지도에서 목록과 검색으로 이동했다가 돌아올 때 기존 지도 인스턴스와 위치를 재사용해 불필요한 지도 재생성을 줄인다. 목록이나 검색에 직접 들어온 경우 지도를 불러오거나 위치 권한을 요청하지 않는다. 지도와 목록·검색·상세의 기존 URL, 키보드 접근, 포커스 복귀, 기사 위치, 필터, 공유와 SEO를 유지한다. 지도 크기가 실제로 바뀌지 않았을 때 중복 크기 조정을 피하되 숨겼다가 다시 표시되거나 크기가 변경되면 지도를 갱신한다.
