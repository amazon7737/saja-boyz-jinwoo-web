# 구현할 동작

- [ ] 지도를 연 뒤 목록·검색을 오가고 돌아와도 같은 지도 인스턴스가 유지된다. 지도 이외의 직접 진입에서는 지도가 초기화되지 않는다.
- [ ] 숨긴 지도에 속한 시트나 기사 데이터가 목록·검색의 접근성 트리와 상세 화면에 노출되지 않고, 지도 복귀 시 위치·기사 선택·크기 갱신이 유지된다.
- [ ] 지도 크기가 변하지 않은 경우 중복 크기 조정과 마커 배치 재계산을 피하고, 숨김에서 복귀하거나 실제 크기가 변하면 갱신한다.
- [ ] 새 피그마 로고와 공유 이미지를 대응하는 화면 및 공유 메타데이터에 적용한다.
