# 지도용 사건 API 계약 확인 요청

2026-10-10 · 프런트 담당 easter721 / 확인 요청 대상 amazon(GitHub: amazon7737).

실제 네이버 지도와 내 위치는 dev에 머지됐다. 다음 지도 단계는 실제 사건 마커 → 선택 요약/바텀시트 → 필터·클러스터다. 구현을 시작하려면 기사 목록과 별개로 지도에 올릴 사건의 식별·위치·분류·시각 계약을 확정해야 한다. 이 문서는 확정된 서버 스키마가 아니며 아래 필드명과 요청 형식은 합의 전이다.

## 현재 확인된 근거

- [서버 Swagger](https://poem-news.168.107.37.12.sslip.io/docs), [OpenAPI](https://poem-news.168.107.37.12.sslip.io/openapi.json).
- 2026-10-10 조회한 명세의 경로는 `/health`, `/collections`, `/collections/{id}`, `/news`, `/images/{articleID}.jpg`다.
- `NewsItem`은 collection_id, article_id, article, image_status, image_url을 선언한다. 기사 `article_id`는 소문자 16진수 64자리이며, 지도용 사건 ID·좌표·사건 분류·발생 시각은 명세에 보장되지 않는다. article의 additionalProperties 허용을 지도 계약으로 해석하지 않는다.
- 현재 `/news` 검색 및 기사 표시 계약은 [news-api-contract.md](news-api-contract.md)를 유지한다. 기사 발행 시각을 사건 발생 시각으로 취급하지 않는다.
